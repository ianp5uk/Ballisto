Ballisto

A basic ballistic computer for target shooting

Welcome

First you must create at least one ammo set by entering its parameters. You can have as many ammo sets as desired. Next you create at least one firearm and input its parameters. You will link the firearm to the ammo when you use this computer.

This application is provided free of charge and without any guarantee. It is designed for simple target shooting over short to medium range. Use for long distance is likely to be inaccurate as there is no correction for the rotation of the earth, no weather input (a standard sea-level atmosphere is assumed) and spin drift is only a rough estimate.

Ammo

Please add the ammo parameters. You may add any number of different ammo sets, each identified by the name you give it. For .22LR it is best to include the brand and type, e.g. "Eley Club".

The ideal muzzle velocity is measured for your own rifle. Otherwise use the manufacturer's figure. Grey values are defaults or examples – type over them.
