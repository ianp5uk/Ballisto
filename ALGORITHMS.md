# Ballisto – ballistic algorithms and their sources

Everything described here is implemented in `web/ballistics.js` (solver) and
`web/dragtables.js` (drag data, generated by `tools/make_drag_tables.py`).
No proprietary code, paid library or licensed data set is used.

## 1. Trajectory model – point-mass (3-DOF)

The bullet is treated as a point mass acted on by gravity and aerodynamic drag
(the "modified point-mass" refinements such as yaw of repose, aerodynamic jump
and Magnus force are not modelled).

- Robert L. McCoy, *Modern Exterior Ballistics: The Launch and Flight Dynamics
  of Symmetric Projectiles*, Schiffer Publishing, 1999 (2nd ed. 2012),
  chapter 5 "The Flat-Fire Point-Mass Trajectory" and chapter 4 (drag).
- The same formulation is used by JBM Ballistics
  (<https://jbmballistics.com/ballistics/calculators/help/traj_drift/traj_drift_exp.shtml>)
  and by the open-source py-ballisticcalc
  (<https://github.com/o-murphy/py-ballisticcalc>), against which Ballisto is tested.

Equations of motion (x downrange, y up, z right; **v**ᵣ = velocity relative to the air):

```
d**v**/dt = −(ρ·π / (8·BC)) · C_D,G(M) · |**v**ᵣ| · **v**ᵣ  −  g·ŷ
```

This follows directly from `a = ρ v² C_D A / (2m)` with `A = πd²/4`, the
ballistic coefficient definition `BC = m / (d²·i)` and `C_D = i · C_D,G(M)`,
where `C_D,G` is the drag coefficient of the chosen standard projectile at Mach
number `M = |vᵣ| / c`. BC is entered in the usual lb/in² and converted to kg/m²
(×703.0696).

Integration: classical 4th-order Runge–Kutta in time, step
`dt = clamp(X / v₀ / 400, 20 µs, 2 ms)`, with linear interpolation to the exact
target distance (error < 0.01 mm at any range).

## 2. Atmosphere

No weather input is taken (the app is user-input only, no sensors), so the
**ICAO International Standard Atmosphere at sea level** is used: 15 °C,
1013.25 hPa, dry air, ρ = 1.2250 kg/m³, speed of sound 340.294 m/s. Density
and speed of sound are varied with height above the muzzle using the ISA
tropospheric lapse rate (−6.5 K/km, ρ ∝ T^4.2559), which only matters for long,
high-angle shots.

- ICAO Doc 7488/3, *Manual of the ICAO Standard Atmosphere*, 1993.

Consequence: cold or hot days, altitude and humidity are not corrected. For
rimfire at 10–100 m the effect on sight corrections is normally below one click;
it grows with range.

## 3. Drag functions (G1, G2, G5, G6, G7, G8, GI, GL, RA4)

| Model | Source of the C_D-vs-Mach table |
|---|---|
| G1, G2, G5, G6, G7, G8, GI | US Army Ballistic Research Laboratory (BRL) standard drag functions, as tabulated by JBM Ballistics: <https://jbmballistics.com/downloads.html> (`mcg1.txt` … `mcgi.txt`) |
| RA4 | Standard .22 LR (heeled lead rimfire) drag function, table published by JBM Ballistics: <https://jbmballistics.com/downloads/ra4.txt>. Same table as used in py-ballisticcalc (`TableRA4`). Eley publishes its .22LR BCs against RA4: <https://eley.co.uk/category/ammunition-faq/> |
| GL | E. D. Lowry, *Exterior Ballistics of Small Arms Projectiles*, Research Dept., Winchester-Western Division, Olin Mathieson Chemical Corp., 1965 – retardation functions tabulated by JBM: <https://jbmballistics.com/downloads/olin.txt> |

The raw files are copied unmodified into `tools/dragdata/`.

GL has no published C_D-vs-Mach table; Lowry only gives G1 and GL
retardation functions against velocity, on the same basis. Ballisto derives it as

```
C_D,GL(M) = C_D,G1(M) × GL(v) / G1(v)        (Lowry's columns, same v)
```

which reproduces GL being identical to G1 below ~1500 ft/s and rising above
it. Lowry lists GL only up to 3600 ft/s; above that the ratio is held constant.
This is a documented approximation – for jacketed bullets use G1 or G7 instead.

Mach values outside a table are clamped to its end values (all tables cover
Mach 0–4 or 0–5).

## 4. Zeroing and the elevation correction

Line of sight is level and `h` (sight height) above the bore. For a range `X`
the bore elevation θ(X) that makes the bullet cross the line of sight at `X`
is found by:

1. bracketing on a geometric grid of angles 0.0005 … 0.8 rad (so very long,
   high-angle solutions are found correctly; if no angle reaches, a
   golden-section search for the maximum height at `X` decides whether the
   target is reachable at all);
2. bisection to 10⁻¹¹ rad.

The sight correction when changing from zero range `Rz` to range `R` is

```
Δθ = θ(R) − θ(Rz)          (positive = dial UP)
```

This is exact within the model (it is not the small-angle "drop ÷ range"
approximation), so it stays correct to 3000 m.

Units: 1 MRAD = 0.001 rad; 1 MOA = 1/60° = 0.290888 MRAD (true minute of
angle; 1.047 in at 100 yd). Clicks = |correction| ÷ click value, rounded to
the nearest whole click. The result shows both MRAD and MOA; the row in the
rifle's own unit uses its click value, the other row assumes the common default
(0.1 MRAD or 0.25 MOA).

## 5. Windage

**Miss correction** – purely geometric: the strike must move by distance `d` at
range `R`, so the correction is `atan(d / R)`, in the direction the user chose.
Nothing else is added, because the observed miss already contains wind, spin
drift, etc.

**Crosswind** – the full-value (90°) crosswind `w` is included in the relative
velocity **v**ᵣ = (vₓ, v_y, v_z − w) and the trajectory re-integrated at the
new zero angle. Drift `z(R)` is returned and the correction is
`−atan(z / R)`. For a point mass this reproduces Didion's "lag rule"
`drift = w·(t − R/v₀)` (R. McCoy, *Modern Exterior Ballistics*, §5.5).

**Spin drift (crosswind mode only, estimate)** – Bryan Litz's empirical formula

```
SD = 1.25 · (Sg + 1.2) · t^1.83   inches, t = time of flight (s)
```

(B. Litz, *Applied Ballistics for Long Range Shooting*, 2009, ch. 8). The
correct gyroscopic stability `Sg` needs bullet length and calibre, which the
specification does not collect, so a nominal **Sg = 1.5** is used. Only the
twist *direction* (right = drift right) and "twist 0 = no spin" are therefore
honoured; the twist *rate* is stored but does not change the estimate.
Because zeroing at `Rz` already absorbed the spin drift there as an angle, only
the change is applied: `SD(R) − SD(Rz)·R/Rz`. At 100 m this is usually a few
millimetres to ~1 cm for .22 LR.

Not modelled: Coriolis / Eötvös (earth rotation), aerodynamic jump, uphill /
downhill shooting angle, head/tail wind, powder temperature sensitivity.

## 6. Other outputs and checks

- Energy at target: ½ m v² (the only use of bullet weight – with a G-model BC
  the trajectory does not depend on weight separately).
- Errors: range < 10 yd or > 10 000 yd, muzzle velocity < 100 ft/s or
  > 6000 ft/s, BC ≤ 0 or > 2, target beyond maximum range, no ammo selected.
- Warnings: bullet goes from supersonic to subsonic before the target
  (transonic), range beyond 500 m.

## 7. Verification

`node tests/ballistics.test.js` compares Ballisto with py-ballisticcalc 2.3.1
(LGPL-3.0; used only as an external reference, none of its code is included)
for RA4 / G1 / G7 cases from 23 m to 3000 m. Agreement: elevation within
0.005 MRAD or 0.5 %, drift, velocity and time of flight within 0.5 %
(actual worst case: 0.03 % at 3000 m). `tools/compare_pyballisticcalc.py`
regenerates the reference numbers.
